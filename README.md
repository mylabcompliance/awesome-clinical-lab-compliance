# Awesome Clinical Lab Compliance [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of free, reliable resources for running a CLIA-compliant clinical laboratory in the United States: regulations, official lookups, datasets, open-source tools and templates.

Contributions welcome: see [CONTRIBUTING.md](CONTRIBUTING.md). Official sources first, no paid-only content, no affiliate links.

## Regulations and official guidance

- [42 CFR Part 493 (eCFR)](https://www.ecfr.gov/current/title-42/chapter-IV/subchapter-G/part-493) - The CLIA regulations, always current.
- [42 CFR 493 Subpart M: Personnel](https://www.ecfr.gov/current/title-42/chapter-IV/subchapter-G/part-493/subpart-M) - Director, consultant, supervisor and testing personnel qualifications (amended effective Dec 28, 2024).
- [CMS CLIA program](https://www.cms.gov/medicare/quality/clinical-laboratory-improvement-amendments) - Program overview, policies and guidance.
- [CDC CLIA](https://www.cdc.gov/clia/) - Test complexity, guidance and educational materials.
- [CMS State Operations Manual, Appendix C](https://www.cms.gov/Regulations-and-Guidance/Guidance/Manuals/Downloads/som107ap_c_lab.pdf) - Surveyor interpretive guidelines for laboratories.

## Official lookups and forms

- [FDA CLIA test complexity database](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfClia/search.cfm) - Look up whether a test is waived, moderate or high complexity.
- [QCOR CLIA laboratory lookup](https://qcor.cms.gov/) - Search certified labs and certificate status.
- [Form CMS-116](https://www.cms.gov/medicare/cms-forms/cms-forms/downloads/cms116.pdf) - CLIA application for certification.
- [CMS CLIA state agency contacts](https://www.cms.gov/Regulations-and-Guidance/Legislation/CLIA/Downloads/CLIASA.pdf) - Who processes CLIA applications in each state.

## State requirements

- [CLIA State Requirements dataset](https://github.com/mylabcompliance/clia-state-requirements) - Open 50-state dataset of state lab licensing, personnel licensing and CLIA agencies (JSON/CSV).
- [ASCP BOC: states that license laboratory personnel](https://www.ascp.org/boc/explore-credentials/state-licensure) - Personnel licensure overview.

## Accreditation organizations

- [CMS list of approved accreditation organizations](https://www.cms.gov/files/document/cms-gov-ao-list.pdf)
- [College of American Pathologists (CAP)](https://www.cap.org/laboratory-improvement/accreditation)
- [COLA](https://www.cola.org/)
- [The Joint Commission](https://www.jointcommission.org/)

## Open data

- [CMS Provider of Services File: Clinical Laboratories](https://data.cms.gov/provider-characteristics/hospitals-and-other-facilities/provider-of-services-file-clinical-laboratories) - Quarterly file of every CLIA lab.
- [CLIA Lab Directory](https://github.com/mylabcompliance/clia-lab-directory) - The CMS file cleaned into per-state CSVs of active labs with decoded certificate and facility types.

## Open-source tools

- [Lab QC Tools](https://github.com/mylabcompliance/lab-qc-tools) - Westgard rules with Levey-Jennings chart, method verification calculator and CLIA personnel qualification checker; runs in the browser.
- [Cloudflare Lead-Capture Worker](https://github.com/mylabcompliance/cloudflare-lead-capture-worker) - Quiz, call-to-action bar and lead email for lab service websites.

## Templates

- [CLIA Document Control Starter Kit](https://github.com/mylabcompliance/clia-document-control-starter) - SOP template, six-element competency assessment, personnel file checklist, method verification plan and CSV logs.

## Quality control and statistics

- [Westgard QC](https://www.westgard.com/) - Background on QC rules, sigma metrics and method validation.
- [CLIA proficiency testing acceptance limits (42 CFR 493 Subpart I)](https://www.ecfr.gov/current/title-42/chapter-IV/subchapter-G/part-493/subpart-I) - Regulated analytes and PT criteria.
